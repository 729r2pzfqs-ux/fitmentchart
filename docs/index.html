How the data is built

Every towing, oil, tire, battery and wiper value links to the document it came from: an owner's manual page, an OEM towing guide or spec sheet, or (flagged as such) a third-party reference. Engines and fuel economy come from the EPA, dimensions from Transport Canada, and recalls and crash ratings from NHTSA. Where no source gives a value, we leave it blank instead of guessing.
